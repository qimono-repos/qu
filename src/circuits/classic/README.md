# Classical circuits

Tiny cross-language project for the Week 4 classical circuit-model exercise.

The Python script, Jupyter notebook, and Clojure project implement the same 2-bit-by-2-bit unsigned multiplier using Boolean gates. Inputs are bits (a1,a0,b1,b0), and outputs are returned in (c3,c2,c1,c0) order.

This is an educational gate-level construction, not a claim of a universal minimum over every possible circuit architecture.
