# MIT xPRO Finale Quiz · Q5: Process Tomography vs Randomized Benchmarking

Source: Q5 posted in the Qimono `#mit` Finale Quiz Slack thread on 2026-10-29. This repository note intentionally stores the prompt and candidate options only, not selected choices or an answer verdict.

**Question type:** Select all that apply.

**Question:** What fundamentally distinguishes process (gate) tomography from randomized benchmarking?

**Candidate options:**
1. There are no differences; both determine the fidelity of a particular gate.
2. Process tomography requires far less data for its analysis and can therefore benchmark circuits of arbitrary size.
3. Process tomography enables identification of individual noise channels.
4. Process tomography is in general unlike randomized benchmarking susceptible to initialization and measurement errors.
